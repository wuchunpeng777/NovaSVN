# Task: 0.1 初始化工程

## 目标

完成 NovaSVN 的 Tauri + Svelte + TypeScript + Rust 工程初始化，让项目具备可启动、可扩展、可继续开发后续 SVN 客户端功能的基础骨架。

## 背景

根据 `doc/开发计划.md`，NovaSVN 的第一个开发功能是 `0.1 初始化工程`。该功能是后续前后端通信、主布局、任务队列、SVN 命令封装和完整客户端能力的基础。

当前仓库主要包含设计文档和开发计划，尚未建立应用工程。需要先创建 Tauri 桌面应用骨架，并按设计文档确定的技术栈落地：

- 前端：Tauri + Svelte + TypeScript
- Diff UI：Monaco Editor，后续阶段集成
- 后端：Rust
- SVN 集成：第一版调用 `svn` 命令行
- 打包：Tauri bundler

## 修改要求

- 必须遵守：
  - 使用开发计划中的技术栈：Tauri + Svelte + TypeScript + Rust。
  - 应用名称使用 `NovaSVN`。
  - 建立前端和 `src-tauri` 基础目录。
  - 后端预留 `svn`、`workspace`、`task`、`staging`、`error` 模块边界。
  - 前端预留 `app shell`、路由、状态管理、组件目录。
  - 中文沟通，代码注释使用中文。
  - 不实现 SVN 业务功能，只做初始化工程和骨架。
- 不允许做：
  - 不引入 Electron。
  - 不实现工作副本打开、状态扫描、提交等阶段 1 功能。
  - 不集成 Monaco Editor，Monaco 属于阶段 2。
  - 不实现 Windows/macOS 右键菜单。
  - 不提交密钥、本机路径或临时缓存。
