# Release: 7.3 设置和用户偏好

## Release Log

### 2026-07-03 实现设置和用户偏好

#### 背景

产品化前需要统一管理 SVN 路径、分支池路径、Diff 偏好、提交模板、大文件阈值、Unity 规则和外部工具路径。

#### 改动

- 新增 `appSettingsStore`，通过 localStorage 持久化应用设置。
- 设置页支持 SVN 可执行路径、分支池默认路径、Diff 模式、空白字符显示、提交模板、大文件阈值、Unity 规则和外部 Diff/Merge 工具路径。
- 设置变更后立即同步到 SVN 检测、提交模板、diff viewer、分支池路径建议和安全检查。
- 增加路径控制字符、相对路径、可执行文件名等校验。
- 外部 Diff/Merge 工具接入右侧详情面板。
- 补充设置保存恢复、路径校验、Unity 分组设置和外部工具校验测试。

#### 影响

用户偏好可以保存和恢复，关键路径输入会在 UI 中给出校验错误。

#### 验证

- 相关提交：`fd39676 实现设置和用户偏好`、`f84b02c 补充设置路径校验`、`636e845 接入外部Diff和Merge工具`、`5ea6892 补充外部工具设置校验测试`。
- 覆盖点：`src/stores/app.ts`、`src/components/workbench/MainWorkspace.svelte`、`src/components/workbench/DetailPanel.svelte`。

#### 风险

设置目前保存在浏览器 localStorage，不是后端统一配置文件；清理站点数据会丢失偏好。
