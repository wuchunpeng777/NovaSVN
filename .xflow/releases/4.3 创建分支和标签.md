# Release: 4.3 创建分支和标签

## Release Log

### 2026-07-02 实现创建分支和标签

#### 背景

4.1 已实现仓库浏览，4.2 已识别 trunk、branches、tags。阶段 4 继续需要从现有 URL 创建 branch/tag，以便后续分支工作副本池能使用真实远端分支。

#### 改动

- 后端任务队列新增 `RepositoryCopy` 负载，封装 `svn copy [-r revision] <source> <target> -m <message>`。
- 新增 `create_repository_copy_task` Tauri command，并沿用任务日志和错误展示。
- 前端新增 repository copy API 类型、API client 方法和 taskStore 创建方法。
- 工作区状态新增 branch/tag 创建表单、待完成任务 ID 和错误状态。
- 仓库视图新增创建分支/标签表单，支持源 URL、目标 URL、revision 和提交信息。
- 表单可基于已识别的 branches/tags 目录快速生成目标 URL 初稿。
- 重新运行前端构建、Rust check 和 Rust 单元测试。

#### 影响

用户可以通过任务队列创建 SVN 分支或标签，成功和失败都能在底部任务日志中查看。该能力为后续分支工作副本池打通远端分支来源。

#### 风险

本次不包含 checkout 工作副本池、分支删除或布局持久化。真实创建操作依赖用户权限、仓库路径和 SVN 认证配置，失败信息由 `svn copy` 输出返回。
