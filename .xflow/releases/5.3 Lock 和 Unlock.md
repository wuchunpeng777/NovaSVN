# Release: 5.3 Lock 和 Unlock

## Release Log

### 2026-07-03 实现 Lock 和 Unlock

#### 背景

完整 SVN 客户端需要能显示并操作文件锁。状态扫描已经读取文件状态，后续需要补齐锁状态展示、lock、unlock 和强制 unlock 入口。

#### 改动

- 状态扫描解析工作副本锁和远端锁信息，返回 `lock_state`、`lock_owner` 和 `lock_comment`。
- 后端任务队列新增 `lock_file`、`unlock_file` 和 `force_unlock_file` 操作。
- 右侧详情面板显示锁状态、持锁人、备注，并提供 Lock / Unlock / Force Unlock 按钮。
- 前端按当前锁状态保护 unlock 入口，避免无锁文件误操作。
- 补充锁操作路径校验和任务创建测试。

#### 影响

用户可以直接在文件详情中查看锁状态并执行锁定、解锁或强制解锁。

#### 验证

- 相关提交：`fe24737 实现Lock和Unlock`、`2a3a617 补充强制Unlock入口`、`db83c5a 按锁状态保护文件锁操作`。
- 覆盖点：`src-tauri/src/task.rs`、`src-tauri/src/workspace.rs`、`src/components/workbench/DetailPanel.svelte`。

#### 风险

强制 unlock 仍依赖 SVN 权限和服务端配置，失败时只展示 SVN 原始错误摘要。
