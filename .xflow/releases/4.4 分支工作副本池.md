# Release: 4.4 分支工作副本池

## Release Log

### 2026-07-02 实现分支工作副本池

#### 背景

阶段 4 已具备仓库浏览、分支/标签识别和创建分支/标签能力。为了支持多分支并行工作，需要将远端分支 URL 与本地工作副本路径关联，并提供快速切换入口。

#### 改动

- 后端新增 `branch_pool` 模块，将分支工作副本池配置保存到应用数据目录 `branch-pool.json`。
- 后端新增读取、保存、删除池项的 Tauri command。
- 任务队列新增分支 checkout 任务，封装 `svn checkout [-r revision] <branch_url> <local_path>`。
- 前端新增分支池 API 类型、API client 方法、taskStore checkout 创建方法和 branchPoolStore。
- 分支池视图新增 checkout 创建、复用已有工作副本、池项列表、切换和移除功能。
- 切换池项复用现有打开工作副本流程，不执行 `svn switch`。
- 删除池项前使用确认弹窗，且只移除池配置，不删除真实工作副本目录。
- 重新运行前端构建、Rust check 和 Rust 单元测试。

#### 影响

用户可以维护多个分支工作副本池项，并快速切换当前工作区。每个工作副本仍使用既有以路径和 repository URL 区分的草稿存储，暂存草稿和本地状态天然隔离。

#### 风险

当前不会后台自动扫描所有池项，本地改动数量保存为创建/复用时传入值，后续可扩展为按需刷新。checkout 成功后的 revision 主要来自用户输入或工作副本打开后的摘要刷新。
