# Release: 1.5 文件 Diff

## Release Log

### 2026-07-02 实现文件 Diff

#### 背景

`1.4 本地改动列表` 已经支持搜索、分组和选择文件。下一步需要把选中文件和后端 diff 命令连接起来，让用户能审查 modified、added、deleted 文件的文本差异。

#### 改动

- 扩展 `src-tauri/src/workspace.rs`，新增文件 diff 请求和响应类型。
- 新增 `get_file_diff` Tauri command。
- 后端执行 `svn diff <path>`，请求包含工作副本 root、文件相对路径和可选 SVN 可执行文件路径。
- Diff 路径使用 `Command::arg` 传参，支持包含空格的文件路径。
- 后端识别二进制 diff 输出，返回 `binary` 标识，避免前端崩溃。
- 前端补齐 diff 类型和 API client 方法。
- `workspaceStore` 保存当前文件 diff、加载状态和错误状态。
- 点击或切换选中文件后自动请求 diff。
- 右侧详情区新增普通文本 diff 面板，支持文本 diff、二进制提示和空 diff 提示。

#### 影响

NovaSVN 现在可以对选中的本地改动文件展示基础文本 diff，为后续文件审查、虚拟暂存和提交做准备。

#### 风险

- 本阶段未集成 Monaco Editor，diff 只是普通等宽文本展示。
- 本阶段不支持 hunk 选择、行级选择或暂存。
- 二进制文件只显示不可预览提示，不展示内容。
