# Release: 0.4 任务队列基础

## Release Log

### 2026-07-02 实现任务队列基础

#### 背景

`0.3 应用主布局` 已经提供底部任务队列占位，但后端 `task` 模块仍是空壳。后续状态扫描、提交、更新、清理等 SVN 操作都需要统一的后台任务、日志和失败展示基础。

#### 改动

- 新增 Rust 内存任务队列，支持 `pending`、`running`、`success`、`failed`、`cancelled` 状态。
- 任务记录包含稳定 `task_id`、标题、日志、错误、创建时间和更新时间。
- 新增创建模拟任务、读取任务列表、读取任务详情和取消任务的 Tauri commands。
- 模拟任务按串行队列执行，可验证成功和失败状态流转。
- 前端补齐任务类型、API client 方法和任务 store。
- 底部任务队列从静态占位改为真实任务列表、当前任务日志和失败信息展示。
- 在底部任务区提供“模拟成功”和“模拟失败”开发验证入口。
- 补齐 Windows Tauri 构建所需 `icon.ico`，并替换损坏的占位 `icon.png`。

#### 影响

后续耗时 SVN 功能可以复用同一任务队列模型，不需要在各功能中重复实现 loading、日志、失败状态和任务详情 UI。当前队列仅保存在内存中，符合本阶段范围。

#### 风险

- 取消功能本阶段只支持尚未运行的 pending 任务，不能终止正在运行的外部进程。
- 当前任务执行状态通过前端轮询刷新，后续可以改为 Tauri 事件推送。
- 任务队列尚未持久化，应用重启后任务记录会清空。
