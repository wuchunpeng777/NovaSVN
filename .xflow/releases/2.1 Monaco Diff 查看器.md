# Release: 2.1 Monaco Diff 查看器

## Release Log

### 2026-07-02 Monaco Diff 查看器

#### 背景

阶段 1 的 Diff 只展示 `svn diff` 纯文本。进入阶段 2 后，需要为代码审查提供更现代的 diff 查看体验，包括语法高亮、双栏/行内切换和空白字符显示，同时保证大文件和二进制文件不会卡死 UI。

#### 改动

- 引入 `monaco-editor`，新增 `MonacoDiffViewer` 组件。
- 右侧 Diff 区接入 Monaco Diff Viewer，支持只读、双栏、行内和空白显示开关。
- 后端新增 `get_file_content_diff` command，返回 base / working 两份文本内容、语言标识、大文件和二进制降级状态。
- 前端 API、类型和 `workspaceStore` 增加 content diff 状态与加载错误。
- 选择文件或刷新状态时同时加载纯文本 diff 和 Monaco content diff。
- Vite 配置提高 Monaco chunk size warning 阈值，并显式配置 Monaco editor worker。

#### 影响

用户在右侧详情区可以用 Monaco 查看常见源码文件 diff，获得语法高亮和更清晰的审查体验。超过 512KB 的文件和二进制文件会降级提示，避免 UI 被大文件拖慢。

#### 风险

Monaco 引入了更大的前端资源体积。当前仅加载基础 editor worker 和常用语言贡献，未来如需更多语言高亮可能还要扩展语言映射。本阶段不支持 hunk 级暂存、行级选择、评论或任意 revision 对比。
