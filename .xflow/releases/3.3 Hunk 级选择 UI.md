# Release: 3.3 Hunk 级选择 UI

## Release Log

### 2026-07-02 实现 Hunk 级选择 UI

#### 背景

开发计划 3.3 要求在 Diff 中展示 hunk 选择控件，支持 stage/unstage hunk，显示文件部分暂存状态，并在文件变化后让 hunk 选择失效。

#### 改动

- workspaceStore 新增 ParsedFileDiff 状态、parsed diff 错误状态和 selectedHunks 草稿状态。
- 选中文件加载 svn diff 后调用 `parseUnifiedDiff`，并把当前文件的 ParsedFileDiff 传给详情面板。
- 右侧 Diff 区新增 Hunk 选择面板，可勾选/取消勾选单个 hunk，并显示已选择数量。
- hunk 选择按 filePath、fileDigest 和 hunkId 保存，刷新状态后文件摘要变化会自动清理失效选择。
- workspace draft 增加 selectedHunks 持久化字段，应用重启后可恢复仍有效的 hunk 选择。

#### 影响

- 用户可以在支持的文本 modified 文件上选择单个或多个 hunk。
- binary、property-only、rename-like 等不支持场景继续显示不支持原因。
- 后续 3.4 selected patch 生成可以直接读取 selectedHunks 和 ParsedDiff。

#### 风险

- 当前已暂存预览只显示 hunk 选择摘要，不生成 selected patch 内容。
- hunk 选择 UI 暂时位于 Monaco diff 下方，后续可在 3.4/3.6 继续增强预览和提交闭环。
