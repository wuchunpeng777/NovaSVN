# Release: 4.2 分支和标签识别

## Release Log

### 2026-07-02 实现分支和标签识别

#### 背景

4.1 已实现基础 Repository Browser，但仓库视图仍不能识别标准 SVN 布局，也不能直接展示 branches 和 tags 下的候选列表。阶段 4 后续创建分支、标签和工作副本池需要先获得这些结构化入口。

#### 改动

- 前端工作区状态新增仓库布局路径、trunk/branches/tags 任务 ID、加载结果、错误和加载状态。
- 复用 4.1 的仓库列表任务，按用户输入的布局 root 加载 trunk、branches、tags 三个路径。
- 仓库视图新增分支和标签识别面板，支持手动编辑 trunk、branches、tags 路径。
- UI 展示 trunk 是否识别成功、分支数量、标签数量，以及分支/标签列表的名称、revision、author 和 date。
- 分支和标签列表项可直接跳转到对应仓库目录继续浏览。
- 重新运行前端构建、Rust check 和 Rust 单元测试。

#### 影响

标准 SVN 仓库可以按默认布局识别 trunk、branches、tags；非标准仓库可以临时手动输入布局路径后识别。该能力为后续创建分支/标签和分支工作副本池提供基础数据。

#### 风险

本次未实现布局配置持久化，也未实现分支/标签创建。认证、权限不足、路径不存在等错误依赖底层 `svn list --xml` 任务返回，并在对应布局项中展示。
