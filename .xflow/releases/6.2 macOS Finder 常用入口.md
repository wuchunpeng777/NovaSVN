# Release: 6.2 macOS Finder 常用入口

## Release Log

### 2026-07-03 实现 macOS Finder 常用入口

#### 背景

macOS 侧需要从 Finder 进入 NovaSVN 常用操作。考虑系统权限和安装复杂度，第一版采用 Quick Actions/Services 脚本。

#### 改动

- 新增 `scripts/macos-finder-quick-actions.sh`，生成 Finder Quick Actions。
- 支持 Open、Commit、Update、Diff、Log、Revert、Cleanup 和 Branch Workspace。
- Quick Action 通过 `open -a NovaSVN --args` 传递 action 和路径。
- 增加权限提示，指导用户在系统设置中启用服务或 Quick Actions。
- 与 Windows 入口复用后端启动意图和前端 action 分发。
- 脚本校验覆盖 action 列表和路径参数传递。

#### 影响

macOS 用户可以从 Finder 选择文件或目录后打开 NovaSVN 并进入对应操作视图。

#### 验证

- 相关提交：`e5affa1 实现macOS Finder常用入口`、`883659b 补充Finder入口权限提示`。
- 覆盖点：`scripts/macos-finder-quick-actions.sh`、`src-tauri/src/system_integration.rs`、`src/App.svelte`。

#### 风险

Finder Quick Actions 的可见性受系统权限和用户设置影响，需要用户按提示启用。
