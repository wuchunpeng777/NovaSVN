# Release: 6.1 Windows Explorer 右键菜单

## Release Log

### 2026-07-03 实现 Windows Explorer 右键菜单入口

#### 背景

跨平台产品化版本需要提供系统文件管理器入口。Windows 侧先实现 Explorer 右键菜单，作为打开 NovaSVN 并进入对应视图的入口。

#### 改动

- 新增 `scripts/windows-explorer-menu.ps1`，支持安装和卸载 Explorer 菜单项。
- 菜单覆盖 Open、Commit、Update、Diff、Log、Revert、Cleanup 和 Branch Workspace。
- 启动命令传递 `--novasvn-action` 和 `--novasvn-path`。
- 后端新增启动意图解析和 action 白名单。
- 前端启动后根据 action 打开路径并切换到对应视图或触发 update/cleanup。
- 脚本校验覆盖文件、目录和目录背景路径占位符。

#### 影响

Windows 用户可以从 Explorer 进入 NovaSVN 常用操作入口。该实现不做状态图标覆盖。

#### 验证

- 相关提交：`6c24e10 实现Windows右键菜单入口`、`3150d0e 修正Explorer目录入口路径`、`a03daec 校验Explorer菜单安装路径`。
- 覆盖点：`scripts/windows-explorer-menu.ps1`、`src-tauri/src/system_integration.rs`、`src/App.svelte`。

#### 风险

真实注册表安装需要在 Windows 环境执行；当前仓库内验证以脚本和参数分发检查为主。
