# Release: 7.1 自动化测试

## Release Log

### 2026-07-03 补充自动化测试

#### 背景

阶段 7 需要提升稳定性和可维护性，为核心 Rust 模块、SVN 流程、前端组件和端到端冒烟提供测试入口。

#### 改动

- Rust 核心模块补充单元测试，覆盖 diff parser、selected patch、任务队列、分支池、影子工作副本、诊断和系统入口。
- 新增 `test:components`，通过 Vitest 跑前端 store 和组件测试。
- 新增 `test:svn` 和 `test:svn:partial` PowerShell 脚本，建立一次性 SVN 测试仓库并覆盖基础提交、状态和部分提交流程。
- 新增 Playwright E2E 冒烟测试入口 `test:e2e`。
- 补充组件测试、系统入口参数测试、属性状态流程测试、冲突状态流程测试等覆盖。

#### 影响

核心逻辑可以通过 Rust、Vitest、SVN 脚本和 Playwright 分层验证，降低后续功能回归风险。

#### 验证

- 相关提交：`89cada9 补充自动化测试`、`f8ab99e 补充前端组件测试`、`005b3bf 补充端到端冒烟测试`、`a74b111 补充SVN流程测试脚本`。
- 覆盖点：`package.json`、`scripts/test-svn-workflow.ps1`、`scripts/test-svn-partial-commit.ps1`、`tests/e2e/workbench-smoke.spec.ts`。

#### 风险

SVN 集成脚本依赖本机 PowerShell 和 SVN 命令行环境，不作为每次本地快速验证的强制门禁。
