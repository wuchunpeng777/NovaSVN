# Release: 6.5 Unity 文件分组和提醒

## Release Log

### 2026-07-03 实现 Unity 文件分组和提醒

#### 背景

Unity 项目常见目录和资源类型需要更贴近项目语义的分组和提醒，包括 Addressables、ProjectSettings、Packages、Scene、Prefab、大资源和生成目录。

#### 改动

- 改动列表新增 Unity 分组模式。
- `unityGroupLabel` 支持 Addressables、ProjectSettings、Packages、Scene、Prefab 和 Assets 分组。
- 设置页支持配置 Unity 分组规则。
- 安全检查新增 Unity 大资源文件提醒。
- 新增 Library、Temp、Logs、obj 等生成目录提醒和过滤。
- 补充 Unity 分组、大资源和生成目录提醒测试。

#### 影响

Unity 工作副本中的资源改动更容易按项目语义浏览，提交前能看到大文件和生成目录风险。

#### 验证

- 相关提交：`111f047 实现Unity文件分组和提醒`、`349417b 支持Unity分组规则配置`、`a1f7185 增加生成文件过滤`。
- 覆盖点：`src/lib/unity.ts`、`src/components/workbench/MainWorkspace.svelte`、`src/stores/app.ts`。

#### 风险

分组规则仍是内置分类加本地开关，暂不支持用户自定义正则。
