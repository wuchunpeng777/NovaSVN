# Release: 5.6 SVN Properties 和 Externals

## Release Log

### 2026-07-03 实现 SVN Properties 和 Externals

#### 背景

完整 SVN 客户端需要能查看和编辑属性，并识别 `svn:externals` 对工作副本状态的影响。

#### 改动

- 后端新增 `get_svn_properties` 和 `set_svn_property` command。
- 使用 `svn proplist --xml`、`svn propget`、`svn propset` 和 `svn propdel` 读取、保存或删除属性。
- 右侧详情面板新增属性列表、属性编辑表单和 `svn:externals` 预览。
- 保存或删除属性前要求用户确认。
- 安全检查和主视图补充 externals 状态提醒。
- 补充属性名校验、属性删除、属性状态扫描和流程测试。

#### 影响

用户可以查看、编辑和删除普通 SVN 属性，并能看到 externals 配置和相关提交风险提示。

#### 验证

- 相关提交：`37221ed 实现SVN属性和Externals`、`15fb5f0 支持删除SVN属性`、`f928fee 补充Externals状态提醒`。
- 覆盖点：`src-tauri/src/workspace.rs`、`src/components/workbench/DetailPanel.svelte`、`src/stores/app.ts`。

#### 风险

属性编辑仍是基础文本编辑，不提供属性模板或批量属性操作。
