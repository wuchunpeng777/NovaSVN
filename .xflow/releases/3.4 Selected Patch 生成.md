# Release: 3.4 Selected Patch 生成

## Release Log

### 2026-07-02 实现 Selected Patch 生成

#### 背景

开发计划 3.4 要求根据选中 hunk 生成 selected patch，支持多文件 patch，并提供提交前 patch 预览。

#### 改动

- Rust diff 模块新增 GenerateSelectedPatchRequest 和 SelectedPatch 数据结构。
- 后端实现 selected patch 生成，按选中 hunk 输出 patch，未选中 hunk 不进入 patch。
- 新增 `generate_selected_patch` Tauri command 和前端 API/types 封装。
- 添加单元测试覆盖单文件 hunk 过滤和多文件 patch 生成。
- workspaceStore 增加 selected patch 预览状态，右侧 Hunk 选择区提供预览按钮和 patch 文本预览。

#### 影响

- 用户可以基于当前选中的 hunk 生成提交前 patch 预览。
- 后续 3.5/3.6 可复用 selected patch 输出进入影子工作副本流程。

#### 风险

- 当前 patch 仅用于预览，尚未执行 `svn patch` 验证或应用。
- 初版按选中 hunk 独立输出 hunk，复杂相邻 hunk 合并可在后续部分提交闭环中继续增强。
