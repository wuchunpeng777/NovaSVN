# Release: 3.6.1 修正提交任务标记

## Release Log

### 2026-07-02 修正提交任务标记

#### 背景

3.6 Hunk 级部分提交合入后，前端普通提交和部分提交在创建任务成功后记录的待完成任务类型被写反，可能导致后续任务成功监听走错刷新和清理路径。

#### 改动

- 普通整文件提交成功创建任务后改为调用 `markCommitTask`。
- Hunk 级部分提交成功创建任务后改为调用 `markPartialCommitTask`。
- 重新运行前端构建、Rust check 和 Rust 单元测试。

#### 影响

普通提交和 Hunk 部分提交的任务完成处理回到对应流程，提交成功后的状态刷新、暂存清理和提交信息清理更符合实际任务类型。

#### 风险

本次只调整前端任务 ID 标记调用，不改变后端提交流程；剩余风险主要在真实 SVN 工作副本上的端到端部分提交场景仍需手工验证。
