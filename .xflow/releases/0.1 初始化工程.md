# Release: 0.1 初始化工程

## Release Log

### 2026-07-01 初始化 Tauri + Svelte 工程骨架

#### 背景

NovaSVN 在完成设计文档和开发计划后，需要先建立可运行的桌面应用工程骨架，为后续前后端通信、工作台布局、SVN 命令封装、任务队列和完整客户端能力提供基础。

#### 改动

- 创建 Tauri + Svelte + TypeScript + Rust 工程。
- 配置 `package.json`、`vite.config.ts`、`tsconfig.json`、`tsconfig.node.json`。
- 配置 `src-tauri/Cargo.toml`、`tauri.conf.json`、`build.rs` 和 Rust 入口。
- 应用名称设置为 `NovaSVN`。
- 建立前端 `src/` 基础结构，包含 app shell、store、types、lib、components、routes 和样式目录。
- 建立 Rust 后端模块边界，预留 `svn`、`workspace`、`task`、`staging`、`error`。
- 新增 Tauri 图标占位文件。
- 新增 `.gitignore`，排除 `node_modules/`、`dist/`、`src-tauri/target/`、`src-tauri/gen/` 等生成物。
- 新增项目级 `.cargo/config.toml`，用于覆盖本机失效的 Cargo `ustc` 源配置。

#### 影响

项目已经具备可继续开发的桌面应用基础。后续功能可以在当前工程上继续扩展 Tauri command、前端工作台视图、SVN 命令封装和任务队列。

#### 风险

- 当前只是工程骨架，不包含实际 SVN 业务能力。
- 图标仍是占位文件，后续需要替换为正式品牌图标。
- macOS 已验证 `npm run tauri:dev` 可以启动；Windows 开发模式还需要在 Windows 环境中验证。
- Rust 后端预留模块当前会产生未使用 warning，后续接入实际功能后会自然消除。
