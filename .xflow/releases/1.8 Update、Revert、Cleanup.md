# Release: 1.8 Update、Revert、Cleanup

## Release Log

### 2026-07-02 Update、Revert、Cleanup

#### 背景

`1.7 提交信息和文件级提交` 已经接入真实 SVN 提交任务。阶段 1 还需要补齐常用工作副本维护能力，包括更新工作副本、清理工作副本以及撤销单个文件改动。

#### 改动

- 后端任务队列新增 SVN operation payload，支持 `update`、`cleanup` 和 `revert_file`。
- 新增 `create_svn_operation_task` Tauri command，统一创建 SVN 操作任务。
- 前端 API 和类型增加 `SvnOperationKind` 与 `CreateSvnOperationTaskRequest`。
- `taskStore` 增加创建 SVN 操作任务能力，`workspaceStore` 增加待完成 SVN 操作任务追踪。
- 主工作区顶部增加“更新”和“清理”操作入口。
- 右侧文件详情增加“撤销文件”入口，并在执行前弹出二次确认。
- SVN 操作成功后刷新工作副本状态；update 成功后重新打开当前工作副本以更新 revision。

#### 影响

用户可以在 NovaSVN 内执行基础工作副本维护操作，命令输出统一进入底部任务日志。cleanup 失败时会保留 SVN 原始错误摘要，便于定位工作副本锁或元数据问题。

#### 风险

本阶段不支持目录级或批量 revert，不支持 update 到指定 revision，也不处理冲突解决、merge 或 switch。任务队列仍是内存队列，运行中的底层 SVN 进程暂不支持强制终止。
