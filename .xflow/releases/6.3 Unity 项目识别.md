# Release: 6.3 Unity 项目识别

## Release Log

### 2026-07-03 实现 Unity 项目识别

#### 背景

NovaSVN 面向游戏和 Unity 项目，需要在打开工作副本时识别 Unity 项目并自动启用相关规则。

#### 改动

- 工作副本摘要新增 `UnityProjectInfo`。
- 后端根据 `Assets/`、`ProjectSettings/` 和 `Packages/manifest.json` 识别 Unity 项目。
- 主工作区摘要展示 Unity 识别状态。
- 检测到 Unity 项目后自动启用 Unity 规则。
- 设置页保留用户手动开关 Unity 规则的能力。
- 补充 Unity 项目识别测试。

#### 影响

打开 Unity 工作副本后，应用会自动显示 Unity 状态并启用后续 `.meta` 检查、分组和提醒。

#### 验证

- 相关提交：`f9bd609 实现Unity项目识别`、`5f7c9f1 自动启用Unity规则`。
- 覆盖点：`src-tauri/src/workspace.rs`、`src/stores/app.ts`、`src/components/workbench/MainWorkspace.svelte`。

#### 风险

识别逻辑以常见 Unity 目录结构为准，非标准工程可能需要用户手动控制规则开关。
