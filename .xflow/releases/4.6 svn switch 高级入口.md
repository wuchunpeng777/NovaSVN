# Release: 4.6 svn switch 高级入口

## Release Log

### 2026-07-02 实现 svn switch 高级入口

#### 背景

阶段 4 已完成分支池和任务工作区。`svn switch` 是直接修改当前工作副本 URL 的高级操作，需要显式入口、风险提示和任务日志，避免与分支工作副本池的安全切换混淆。

#### 改动

- 后端任务队列新增 `SvnSwitch` 负载，封装 `svn switch <target_url> <working_copy_root>`。
- 新增 `create_svn_switch_task` Tauri command。
- 前端新增 switch API 类型、API client 方法和 taskStore 创建方法。
- 工作区状态新增 switch 目标 URL、待完成任务 ID 和错误状态。
- 本地改动视图新增 `svn switch` 高级入口。
- 执行前检查当前状态扫描结果，有本地改动时要求用户二次确认。
- switch 成功后重新打开当前工作副本并刷新状态；失败时保留任务日志和错误输出。
- 重新运行前端构建、Rust check 和 Rust 单元测试。

#### 影响

用户可以对当前工作副本执行 `svn switch`，并在有本地改动时看到风险确认。该能力不会自动 stash、revert 或清理用户文件，也不会替代分支工作副本池的快速切换。

#### 风险

`svn switch` 本身可能引发冲突或混合状态，当前只展示 SVN 输出和刷新结果，不自动修复冲突。执行前依赖最近一次状态扫描判断本地改动，用户应在执行前刷新状态。
