# Release: 1.1 SVN 命令行检测

## Release Log

### 2026-07-02 接入 SVN 命令行检测

#### 背景

进入阶段 1 前，需要先确认用户本机是否具备可调用的 SVN 命令行环境。后续打开工作副本、状态扫描、diff 和提交都依赖 `svn` 命令可用。

#### 改动

- 扩展 `src-tauri/src/svn.rs`，实现 SVN 命令行检测逻辑。
- 新增 `detect_svn` Tauri command，支持默认检测 PATH 中的 `svn`，也支持指定 `svn.exe` 完整路径。
- 后端执行 `svn --version --quiet` 获取版本，并在 Windows 下通过 `where` 尽力解析可执行文件路径。
- SVN 不存在、执行失败和版本输出异常时复用统一 `NovaError`。
- 前端补齐 SVN 检测类型和 API client 方法。
- 新增前端 SVN 检测状态，保存检测结果、手动路径和错误。
- 右侧详情区新增“SVN 命令行”面板，展示版本、命令、路径，并提供自动检测和手动路径检测入口。

#### 影响

NovaSVN 现在可以在启动后自动检测 SVN 命令行，并让用户用指定路径重新检测，为后续工作副本能力提供环境前置检查。

#### 风险

- 手动 SVN 路径本阶段仅保存在前端运行态，应用重启后不会持久化。
- 检测命令没有进入任务队列，因为它是短命令；后续长耗时 SVN 操作仍应进入任务队列。
- 路径解析依赖系统 `where` 或 `which`，失败时不会阻止版本检测成功，只会显示未解析到完整路径。
