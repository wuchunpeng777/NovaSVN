# Release: 3.2 Unified Diff 解析

## Release Log

### 2026-07-02 实现 Unified Diff 解析

#### 背景

开发计划 3.2 要求解析 svn diff 输出，得到 file diff、hunk 和行变更，并标记是否支持 hunk 级部分提交，为后续 hunk 选择 UI 和 selected patch 生成打基础。

#### 改动

- 新增 Rust `diff` 模块，定义 ParsedDiff、ParsedFileDiff、ParsedHunk、ParsedDiffLine 和 DiffLineKind。
- 实现 svn unified diff 解析，支持多文件、多 hunk、上下文行、新增行、删除行和无换行标记。
- 标记 partial_commit_supported，并为 binary、property-only、rename-like 和无 hunk 文件提供不支持原因。
- 新增 `parse_unified_diff` Tauri command 和前端 API/types 封装，供后续 UI 调用。
- 添加 Rust 单元测试覆盖多文件、多 hunk、binary、property-only、rename-like 和 no-newline 场景。

#### 影响

- 后端已经具备稳定的 diff 结构化解析能力。
- 后续 3.3 hunk 选择 UI 可以直接复用 ParsedDiff 数据结构。

#### 风险

- 解析器当前覆盖常见 SVN unified diff 输出；更复杂的 SVN 属性 diff 或复制/替换场景后续可能需要扩展识别规则。
- 当前只交付解析和 API，不包含 hunk 选择 UI 或 patch 生成。
