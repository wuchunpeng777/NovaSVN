# Release: 1.2 打开工作副本

## Release Log

### 2026-07-02 实现打开工作副本

#### 背景

`1.1 SVN 命令行检测` 已经能确认 SVN 命令行可用。进入工作副本能力前，需要先支持选择或输入本地目录，判断它是否为 SVN 工作副本，并读取基础仓库信息。

#### 改动

- 新增 Tauri dialog 插件依赖和默认权限，用于选择本地目录。
- 扩展 `src-tauri/src/workspace.rs`，实现工作副本摘要、打开请求和最近工作副本存储。
- 后端执行 `svn info --xml <path>` 并用 XML 解析器读取工作副本 root、本地路径、仓库 URL、repository root 和 revision。
- 新增 `open_workspace` 和 `get_recent_workspace` Tauri commands。
- 非工作副本、路径不存在、路径不是目录、XML 解析失败等场景统一返回 `NovaError`。
- 前端补齐工作副本类型、API client 方法和 `workspaceStore`。
- 主工作区新增工作副本面板，支持选择目录、手动输入路径、打开工作副本和展示摘要。
- 最近打开的工作副本保存到应用数据目录，应用重启后可恢复展示。

#### 影响

NovaSVN 现在具备打开普通 SVN 工作副本的基础闭环，后续 `1.3 工作副本状态扫描` 可以直接基于当前工作副本 root 执行 `svn status --xml`。

#### 风险

- 最近工作副本目前只保存一个摘要，不是完整历史列表。
- 本阶段不做工作副本状态扫描，文件改动列表仍是占位。
- 最近工作副本存储是轻量文件，不等同于完整设置系统。
