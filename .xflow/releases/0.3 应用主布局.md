# Release: 0.3 应用主布局

## Release Log

### 2026-07-01 搭建工作台主布局

#### 背景

`0.2 前后端通信基础` 已经建立统一调用和错误展示链路，但主界面仍集中在 `App.svelte`，布局和占位视图不够清晰。后续接入本地改动、暂存区、日志、分支池、仓库浏览和任务队列之前，需要先把工作台结构拆分成稳定组件。

#### 改动

- 将 `App.svelte` 拆分为布局和工作台组件。
- 新增 `Sidebar`，提供工作区、草稿、日志、分支池、仓库和过滤器占位。
- 新增 `Toolbar`，保留后端连接和错误验证入口。
- 新增 `MainWorkspace`，承载本地改动、暂存区、日志、分支、仓库浏览等基础视图占位。
- 新增 `DetailPanel`，承载后端状态、Diff、文件详情、属性、锁状态和检查结果占位。
- 新增 `BottomPanel`，承载提交信息、命令输出和任务队列占位。
- 新增 `src/lib/workbench.ts`，集中管理占位视图数据。
- 扩展 `AppView`、导航项、详情区和工作台视图类型。
- 重写工作台 CSS，使用稳定 grid 布局和固定信息区域，降低后续接入数据时的布局抖动风险。

#### 影响

首屏已经是完整工作台结构，不再是单个临时页面。后续阶段可以分别在中间主视图、右侧详情、底部命令区接入真实 SVN 状态、diff、提交信息和任务队列。

#### 风险

- 当前仍使用占位数据，没有接入真实 SVN 工作副本。
- 尚未集成 Monaco Editor，Diff 区域只是占位。
- 任务队列和提交信息区仍是静态占位，后续 `0.4` 和阶段 `1.7` 需要继续实现。
