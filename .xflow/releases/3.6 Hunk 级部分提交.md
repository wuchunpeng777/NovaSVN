# Release: 3.6 Hunk 级部分提交

## Release Log

### 2026-07-02 实现 Hunk 级部分提交

#### 背景

开发计划 3.6 要求将 selected patch 应用到影子工作副本，在影子工作副本执行提交，提交成功后刷新真实工作副本，失败时保留草稿且不影响真实工作副本。

#### 改动

- 任务队列新增 hunk 级部分提交请求和 PartialCommit payload。
- 部分提交任务会准备或更新影子工作副本，清理影子本地改动，再应用 selected patch。
- selected patch 应用后在影子工作副本执行 `svn commit <files> -m <message>`，命令输出写入任务日志。
- 前端提交区新增“提交选中 Hunk”入口，仅在存在 selected patch 预览时可用。
- 部分提交成功后刷新真实工作副本状态；失败时不清理草稿。

#### 影响

- 一个文件或多个文件的已选择 hunk 可以通过影子工作副本执行部分提交。
- 真实工作副本不会被 selected patch 临时改写。
- 用户可在任务日志中查看 patch、commit 失败的 SVN 原始输出。

#### 风险

- mixed revision 仍未做真实 revision 维度检测，当前依赖既有安全检查和影子 update。
- 部分提交成功后真实工作副本仍需要用户 update 或后续同步机制来收敛本地状态。
