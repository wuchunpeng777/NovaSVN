# Release: 5.1 Log 和文件历史

## Release Log

### 2026-07-02 实现 Log 和文件历史

#### 背景

阶段 5 开始补齐完整 SVN 协作能力。此前日志视图仍是占位，无法查看工作副本历史、文件历史或 revision 的 changed paths。

#### 改动

- 后端新增 `get_svn_log` command，执行 `svn log --xml --verbose --limit <n>`。
- 新增 SVN log XML 解析，返回 revision、author、date、message 和 changed paths。
- 前端新增日志 API 类型、API client 方法和工作区日志状态。
- 日志视图新增读取工作副本日志和选中文件历史的入口。
- 支持按作者、关键字、日期范围和 limit 过滤/分页加载。
- revision 列表展示 changed paths，点击读取后可查看每个 revision 的变更文件。
- 重新运行前端构建、Rust check 和 Rust 单元测试。

#### 影响

用户可以在日志视图查看当前工作副本或选中文件的 SVN 历史，并通过过滤条件缩小结果。该能力为后续 revision diff、分支比较和 patch 导出打基础。

#### 风险

当前只实现日志读取和 changed paths 展示，不包含 revision diff。日志分页为 limit 模式，尚未实现按页追加或按 revision 范围继续加载。
