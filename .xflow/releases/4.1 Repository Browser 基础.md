# Release: 4.1 Repository Browser 基础

## Release Log

### 2026-07-02 实现 Repository Browser 基础

#### 背景

阶段 4 需要进入 SVN 仓库浏览、分支池和任务工作区能力。此前仓库视图仍是占位内容，无法读取 repository root、执行远端目录列表或浏览 trunk、branches、tags。

#### 改动

- 后端新增仓库目录加载任务，封装 `svn list --xml <url>` 并解析文件、目录、revision、author 和 date。
- 任务模型新增可序列化 `result` 字段，仓库列表任务完成后返回结构化目录结果。
- 前端新增仓库列表 API 类型、任务创建方法和工作区仓库浏览状态。
- 仓库视图支持手动输入 URL、使用当前工作副本 `repository_root`、目录进入、返回上级、路径面包屑和错误提示。
- 重新运行前端构建、Rust check 和 Rust 单元测试。

#### 影响

用户可以在仓库视图异步浏览 SVN 远端目录，大目录加载通过既有任务队列执行，不阻塞主界面；后续分支/标签识别可以基于当前仓库浏览结果继续扩展。

#### 风险

当前只实现基础目录浏览，不包含分支/标签自动识别、自定义仓库布局和分支创建。真实 SVN 认证、证书交互或超大目录分页仍依赖命令行行为和后续增强。
