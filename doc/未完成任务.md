- 不实现 Git 式暂存区；文件勾选只表示当前一次提交的目标，不持久化。
- 界面和主要交互以 Versions 的 Working Copy、Timeline、Repository 为基线。
- SVN 操作必须执行真实命令，不能只修改前端状态。
- 每完成一个可独立验收的小功能，必须验证并立即单独提交 Git。
- 中文沟通，代码注释使用中文。
