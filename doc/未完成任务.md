# NovaSVN 未完成任务

更新时间：2026-07-11

本文档记录暂停开发时仍未完成的工作，作为后续恢复入口。完整阶段规划仍以 `doc/开发计划.md` 为准。

## 固定约束

- 不实现 Git 式暂存区；文件勾选只表示当前一次提交的目标，不持久化。
- 界面和主要交互以 Versions 的 Working Copy、Timeline、Repository 为基线。
- SVN 操作必须执行真实命令，不能只修改前端状态。
- 每完成一个可独立验收的小功能，必须验证并立即单独提交 Git。
- 中文沟通，代码注释使用中文。

## 当前基线

- 分支：`main`。
- Delete 已覆盖文件、目录、空版本化目录、ignored/external 排除、工作副本归属、符号链接、排队期间目标身份变化和 Unix 特殊路径。
- 普通 SVN 操作已按 pending task id 消费完成状态，不再依赖当前选中的任务。
- Commit、Partial Commit、Repository、Checkout、Switch、Revision Diff 和 Merge 也已按各自 pending task id 消费完整任务结果。
- 打开工作副本、状态扫描和文件树刷新已有请求世代隔离，旧请求不会覆盖后来打开的工作副本。
- 工作副本根比较覆盖 Windows 盘符、UNC、根目录和 Unix 字面反斜杠。
- 后端重启或任务队列重置导致 pending task 消失时，会解除操作锁定并显示可恢复错误。
- 文件树的递归 `svn info` 已改为流式解析，版本化路径和错误输出都有明确内存边界。
- 工作副本文件和目录支持安全 Move，包含源/目标确认、身份复检和完成刷新。
- 工作副本文件和目录支持安全 Copy，源保持不变，目标作为带历史的新增项进入提交目标。
- 未版本控制文件和目录支持 Ignore；规则按直接父目录写入并保留已有 `svn:ignore` 内容，属性面板显示实际作用目录。
- 工作副本工具栏已改用 Lucide 图标按钮，并按具体操作显示 tooltip、禁用态和运行态。
- Versions 布局已统一侧栏、主表、检查器与分隔尺寸，并在 960px Tauri 最小宽度下保留主表空间。
- 项目侧栏和工作副本检查器支持独立显隐，偏好写入应用设置并在重启后恢复。
- 工作台支持浅色、深色和跟随系统主题，Monaco Diff 与状态颜色同步适配。
- 工作副本表格显示真实 Base/Last revision、最后修改日期和作者，元数据保持流式解析与池化内存边界。
- 工作副本状态区分本地、远端和同时变化，并在远端扫描回退时明确显示未检查状态。
- 文件行按状态提供 Commit、Update、Add、Resolve，文件级 Update 走真实任务，次要操作使用可访问菜单。
- 工作副本文件表支持复选框和 Shift 范围多选，可批量切换提交目标，并以单个真实任务执行 Revert、Move 或 Delete。
