# NovaSVN 性能基准

## 目标

- 50000 文件工作副本能打开。
- 5000 改动文件状态扫描和列表渲染保持可用。
- 大 diff 加载不冻结 UI，并能降级到文本或提示。
- 提交准备阶段可记录耗时，后续用于回归比较。

## 基准脚本

Windows:

```powershell
.\scripts\benchmark-svn-workspace.ps1
```

可选参数：

```powershell
.\scripts\benchmark-svn-workspace.ps1 -Root ".benchmark\svn-large" -FileCount 50000 -ChangedCount 5000
```

重新生成干净基准数据：

```powershell
.\scripts\benchmark-svn-workspace.ps1 -Reset
```

脚本会：

- 使用 `svnadmin create` 创建本地测试仓库。
- checkout 到 `.benchmark/svn-large/wc`。
- 生成 `benchmark/file-xxxxx.txt` 数据集。
- 每次运行前先 `svn revert -R` 回到基线，避免累积改动影响对比。
- 修改前 `ChangedCount` 个文件。
- 记录 `svn status --xml`、单文件 diff、整工作副本 diff、虚拟列表准备和提交准备耗时。
- 传入 `-Reset` 时先删除目标基准目录，避免旧工作副本中的累积改动影响对比。

结果写入：

```text
.benchmark/svn-large/benchmark-results.json
.benchmark/svn-large/benchmark-results.md
```

## 记录格式

```json
{
  "created_at": "2026-07-03T00:00:00.0000000+08:00",
  "file_count": 50000,
  "changed_count": 5000,
  "working_copy": ".benchmark\\svn-large\\wc",
  "results": [
    { "name": "svn status --xml", "elapsed_ms": 0 },
    { "name": "svn diff first file", "elapsed_ms": 0 },
    { "name": "svn diff working copy", "elapsed_ms": 0 },
    { "name": "virtual list prepare 5000 changes", "elapsed_ms": 0 },
    { "name": "commit prepare selected targets", "elapsed_ms": 0 }
  ]
}
```

## 使用方式

1. 运行脚本生成工作副本和结果。
2. 在 NovaSVN 中打开 `working_copy`。
3. 记录状态扫描、虚拟列表准备、列表滚动、搜索过滤、diff 加载和提交准备的主观/客观结果。
4. 对性能相关改动前后保留 `benchmark-results.json` 和 `benchmark-results.md` 作为对比证据。
